# 配置文件目录

本目录包含所有本地配置文件，用于管理系统的各项配置。

## 📁 目录结构

```
base-config/
├── prompts.md      # AI识别提示词配置
├── feishu.md       # 飞书多维表配置（支持按国家）
├── countries.md    # 全球国家代码库
├── INDEX.md        # 配置文件索引
├── CONFIG_GUIDE.md # 配置指南
├── CONFIG_SUMMARY.md # 配置摘要
├── QUICK_START.md  # 快速入门
├── README.md       # 配置说明
└── SERVICE_MANAGER_README.md # 服务管理器说明
```

## 📝 配置文件说明

### 1. prompts.md - AI识别提示词

存储AI识别考勤表格的提示词，包括：
- **主要识别提示词**（ai_prompt）：指导AI如何识别考勤数据
- **继续输出提示词**（continue_prompt）：AI响应被截断时的续写提示

**特点**：
- ✅ 支持Markdown格式
- ✅ 自动备份历史版本
- ✅ 实时生效，无需重启服务

### 2. feishu.md - 飞书多维表配置

配置不同国家的飞书多维表连接信息，包括：
- **默认配置**：当没有匹配国家时使用
- **国家配置**：按ISO国家代码（如FR、CN、DE等）配置

**每个国家配置包含**：
- `bitable_app_token`：飞书多维表应用Token
- `bitable_table_id`：数据表ID
- `field_mapping`：字段映射关系

**特点**：
- ✅ 支持按国家配置不同的多维表
- ✅ 支持不同的字段映射
- ✅ 全球200+国家支持
- ✅ 配置优先级：国家配置 > 默认配置

### 3. countries.md - 全球国家代码库

包含ISO 3166-1标准的所有国家代码：
- 国家代码（Alpha-2）
- 中文、英文、法语国家名称
- 时区信息

**用途**：
- 用于匹配考勤记录的国家信息
- 用于按国家加载对应的飞书配置

## 🔧 使用方法

### 修改AI提示词

**方式一：直接编辑文件**
```bash
vi base-config/prompts.md
```

**方式二：通过前端页面（推荐）**
1. 访问配置管理页面
2. 修改AI识别提示词
3. 点击保存
4. 自动更新到 `base-config/prompts.md`

### 配置飞书多维表

**添加新国家配置**
1. 编辑 `base-config/feishu.md`
2. 找到对应国家或添加新的国家块
3. 填入 App Token 和 Table ID
4. 配置字段映射关系

**示例：为西班牙添加配置**
```markdown
### 西班牙 (ES)

```yaml
ES:
  bitable_app_token: your_spain_app_token
  bitable_table_id: your_spain_table_id
  field_mapping:
    # ... 字段映射
```
```

## 📊 配置优先级

当处理考勤记录时，系统按以下顺序查找配置：

1. **国家专用配置**
   - 例如：处理法国考勤 → 查找 `FR` 配置
   
2. **默认配置**
   - 当没有对应国家配置时使用
   - 必须配置且有效

## 🔐 安全性

- ✅ 配置文件不存储在数据库
- ✅ 支持版本控制（Git）
- ✅ 便于备份和迁移
- ⚠️ 包含敏感信息，勿提交到公开仓库

## 💡 提示

- 修改配置文件后，某些设置可能需要重启服务
- 建议使用前端页面修改配置，避免语法错误
- 修改前建议备份配置文件
- 支持同时配置多个国家的飞书多维表
