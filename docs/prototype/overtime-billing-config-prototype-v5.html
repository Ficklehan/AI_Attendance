定义标准工时、超出标准、周末、节假日、夜间等工时分类。

报价管理

维护标准工时报价，必要时配置加班类目系数或分项报价。

发布配置版本

发布后，后续工时核算和账单核算会使用新版本。

建议发布前确认：适用范围、结算周期、加班分类、报价模式、账单字段映射和对账键。历史账单保留原配置快照，不被静默改写。
